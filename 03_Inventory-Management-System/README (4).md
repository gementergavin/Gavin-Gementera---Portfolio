# SQL & Python Inventory Management Business Process Prototype

## Project Goal
Build a complete, production-style database-driven business process solution with data quality controls, transaction logging, and operational reporting.

## Deliverables
| File                        | Description                                      |
|-----------------------------|--------------------------------------------------|
| `inventory_management.db`   | Full relational SQLite database (items, inventory, transactions, audit log) |
| `inventory_app.py`          | Runnable CLI application with low-stock alerts, transaction recording, and live dashboard |
| `requirements.txt`          | Dependencies                                     |

## Key Features
- Multi-location inventory tracking
- Full transaction history (Receipt, Fulfillment, Adjustment)
- Automated low-stock / reorder alerts
- Data validation on stock movements
- Simple but professional operations dashboard
- Audit logging foundation

## How to Run
```bash
cd 03_Inventory_Management_System
python inventory_app.py
```
